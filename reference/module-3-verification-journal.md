# Module 3 — Journal de vérification participant

> À utiliser pendant l'atelier. Le but n'est pas de tout documenter, mais de garder une trace courte des preuves et des zones encore fragiles.

## Pourquoi ce journal ?

Un agent de code peut aider à construire vite. Ce journal sert à vérifier que vous comprenez ce que vous construisez.

À chaque étape, notez :

1. ce que vous attendiez ;
2. la preuve observée ;
3. ce que vous savez expliquer ;
4. ce qui reste fragile pour le Module 4.
